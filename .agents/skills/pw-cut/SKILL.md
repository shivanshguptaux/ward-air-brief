---
name: pw-cut
description: Cut scope to the smallest deployable golden path when time is short. Use if the build is behind at minute 90 or later.
---

Ask how many minutes are left if the owner did not say. Read `BRIEF.md` and the code. List the smallest version of the golden path that works end to end and can deploy now, and what to remove or stub to get there. Then do it. Add nothing new. Finish with the deploy from `pw-deploy`.
