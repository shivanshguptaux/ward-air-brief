Do not edit anything. In plain language, under 300 words:
- How a request flows through the app, file by file.
- Exactly what Gemini decides and what the code computes.
- What happens when Gemini fails, is slow, or the input is malicious.
- The three weakest points a judge might poke at, with an honest one-line answer for each.
